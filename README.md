A standalone React/Vite concept app for Yellow City Custom Tees in Amarillo, Texas.

## What This App Includes

- Dashboard for shop operations
- POS quick-sale screen
- Orders and production status board
- Custom quote builder
- Inventory starter catalog
- Customer CRM layout
- Loyalty program ideas
- Walk-in kiosk mode
- Public website/service preview
- Admin settings and roadmap

## Deployment

This app is ready for Vercel using the default Vite settings.

Recommended Vercel settings:

- Framework preset: Vite
- Build command: npm run build
- Output directory: dist
- Install command: npm install
