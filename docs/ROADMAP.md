# Yellow City Creator Studio — Production Roadmap

## Vision
Build a one-of-a-kind operating system for Yellow City Custom Tees that combines public quote intake, production tracking, customer relationship management, event sales, team stores, and owner analytics.

## Phase 1 — Stabilize and professionalize
- Production-safe routing
- Production-safe API defaults
- Auth runtime stability
- Public CTA reliability
- Owner-facing proof documentation
- QA checklist

## Phase 2 — Customer intake
- Public quote request page
- Kiosk mode for walk-ins
- Artwork status collection
- Rush/standard deadline selection
- Confirmation screen
- Staff review queue

## Phase 3 — Shop operations
- Orders board
- Quote builder
- POS quick sale
- Inventory tracking
- Customer CRM
- Production status workflow

## Phase 4 — Growth engines
- Route 66 event portal
- Team store workflow
- Business uniform reorder workflow
- Graduation packages
- QR code intake campaigns

## Phase 5 — Owner analytics
- Open revenue
- Orders due soon
- Ready pickups
- Repeat customer rate
- Low-stock alerts
- Event profitability
- Quote conversion rate

## Definition of epic
The app should not feel like generic shop software. It should feel like a custom-built Amarillo print command center designed around how Yellow City Custom Tees actually makes money.
