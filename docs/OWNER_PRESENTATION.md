# Yellow City Creator Studio — Owner Presentation

## Purpose
Yellow City Creator Studio is being upgraded from a working deployment into a serious business operating system for Yellow City Custom Tees.

This platform is designed to help the shop make more money, lose fewer orders, quote faster, and build repeat customer systems around teams, businesses, events, and walk-in traffic.

## Business outcomes

### Faster quotes
Customers should be able to submit basic order details without staff rewriting information from texts, calls, or paper notes.

### Cleaner production flow
Orders should move through a visible workflow:

1. New request
2. Quote created
3. Proof sent
4. Approved
5. In production
6. Quality check
7. Ready for pickup
8. Picked up

### More repeat business
Customer history should support reorders, loyalty tracking, business accounts, school/team programs, and targeted follow-up.

### Better event sales
Route 66 events, local fundraisers, school orders, and booth traffic can use QR intake instead of paper forms.

## First production upgrade scope

This branch starts the professional upgrade work safely away from the production `main` branch.

Planned first production-grade changes:

- Real route structure
- Public quote intake flow
- Demo-safe fallback data
- Owner dashboard metrics
- Route 66 / event merch flow
- Team store workflow
- Deployment proof documentation
- Quality assurance checklist

## Presentation angle for Ashton
This is not just an app. It is a scalable shop operations system that can become the digital backbone for Yellow City Custom Tees.

The goal is to turn daily shop activity into measurable revenue:

- fewer lost orders

- better customer follow-up
- stronger event sales
